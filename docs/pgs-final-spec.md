## 1. 机制总形态（六件套）

```
┌────────────────────────── rollout 侧 ──────────────────────────┐
│ ① 保尾核 b_S：每位置固定候选集 S，S 内按截断文档增量倾斜，S 外恒 = π │
│ ② 截断 c：ℓ̃ = clip(log p_T − log π, ±c) —— 单点话语权限幅        │
│ ③ D 门 + ε 探针：教师有实质异议的位置才干预；5% 随机翻转留因果探针   │
│ ④ D_∞ 预算：每轨迹 Σδ ≤ B_∞，δ = 2ηc 保守记账 —— 硬界           │
│ ⑤ SPS 执行：draft(纯 π 全速) → verify(双前缀打分) → 接受/拒绝重采  │
└──────────────────────────────┬─────────────────────────────────┘
                               │ 逐 token 记账 (log π, log b_S, η, δ, 门状态)
┌──────────────────────────────▼─────────────────────────────────┐
│ ⑥ 训练：GRPO(env outcome) + 分离式校正                           │
│    loss 权重 = W_beh(固定行为校正) × PPO-clip(r_upd 从 1 起步)     │
│    —— 损失中无教师、无蒸馏项、无 critic                            │
└────────────────────────────────────────────────────────────────┘
```

## 2. 组件精确定义

### 2.1 保尾核（NF01 修法采纳）

位置 j，**在看到 draft token 之前**固定候选集
`S_j = topk_K(π(·|h_j)) ∪ topk_K(p_T(·|h_j⊕c_doc))`（K=64 起步）。

```
M_j = Σ_{a∈S_j} π(a)          A_j = Σ_{a∈S_j} π(a)·e^{η_j·ℓ̃_j(a)}
b_j(a) = M_j · π(a)·e^{η_j·ℓ̃_j(a)} / A_j     (a ∈ S_j)
b_j(a) = π(a)                                 (a ∉ S_j)
```

性质（复审确认）：全词表正规分布；S 外接受率恒 1（拒绝只发生在 S 内）；
密度比 `e^{−2ηc} ≤ b/π ≤ e^{2ηc}` 全词表成立；残差只在 S 内、可精确构造。
命题 A/B、记账、预算共用这一个对象。

### 2.2 截断

`ℓ̃_j(a) = clip( log p_T(a|h_j⊕c_doc) − log π(a|h_j), −c, +c )`。
c 的最大抬升/压制倍率为 **e^{2ηc}**（NF10 更正；c=2.5, η=0.5 ⇒ ~12×）。
c 由**目标文档语境**下的 ℓ 分布实测标定（不得沿用 G0 GT 语境的分布——
稀疏性两层拆分裁定），起步 c∈[2,3]。

### 2.3 D 门与探针（NF04/NF07 修法采纳）

```
D_j = Var_{a~π|S_j}[ℓ̃_j(a)]（保尾核对象上计算）
可测性红线：η_j, 门随机数 U_j ∈ σ(h_j, B_rem, 冻结统计, U_j)
           —— 统一为 y_{<j}；严禁依赖 proposal token y_j 或任何后缀
主门：D_j ≥ Θ_D ⇒ η_j = η_max，否则 0
Θ_D：冻结校准值起步（目标语境预扫描的 P85），训练中 robust-EMA 慢更新；
     预注册触发率上下限（如 [5%, 25%]），超限告警降级
探针：ε=5% 翻转门决定；propensity 只记录、只用于事后因果分析，
     不进训练权重（NF07：propensity 在 RL 换测度中相消）
```

### 2.4 预算（NF-C 修法：保守记账）

```
δ_j = 2·η_j·c        （全词表上界直接扣费——封掉 V′-max 与全词表 max 的缺口）
Σ_j δ_j ≤ B_∞         预算余额制在线执行；耗尽后纯 π
⇒ 轨迹 IS log 权重 ∈ [−B_∞, +B_∞] 严格成立
B_∞ 起步 6；更小 B 进主消融（NF10：403× 是不发散界非健康界）
```

### 2.5 SPS 执行（NF04 的 R_max 行为态化）

```
draft：纯 π 全速生成（T=1、无 top-p/k——q≡π 规范锁定）
verify：同一 scoring 通道两次前向（bare + 教师前缀）取 S_j 所需 logprobs；
        接受率 min(1, b_j(y_j)/π(y_j))——y_j∉S_j 时恒接受（保尾核性质）
拒绝：从 S_j 内残差 norm(max(0, b−π)) 重采；以修正前缀续 draft
R_max=4：达到后**该轮后续位置进入 η≡0 状态**（cap-active 计入行为状态并记账，
        b=π 如实记录——行为仍是良定义自适应自回归核）
教师前缀排布：文档/任务静态部分置于动态对话**之前**（KV 跨轮可复用的硬前提，
        NF09；实施时对照现有 GUIDANCE_HEADER 注入位置核实）
数值：接受检验的 b/π 取自同一 verify 前向；draft 与 verify 的 π 残差
     （~1e-3）备案，smoke 必测；命题 A 的精确性**相对 b_S** 陈述
```

### 2.6 训练（NF02/NF03 修法采纳）

```
分离式：per-token 贡献 = W_t · min( r_t·Â, clip(r_t, 1±ε)·Â )
  r_t = π_θ(y_t)/π_old(y_t)        更新步长因子，从 1 起步，clip 只管它
  W_t = 行为校正（消融开关二选一）：
    ③ 单点   W_t = π_old(y_t)/b_t(y_t)              （默认主档，最稳）
    ② 前缀   W_t = Π_{s≤t} π_old(y_s)/b_s(y_s)      （消融档；V-trace 截断可选）
Â：GRPO 组内 advantage，baseline 与 scale 均 leave-one-out（NF03 条件 iv）
每快照单次小步更新（命题 C 条件 v）
损失中无教师项；PGS-AsymA / PGS-SDAR 等变体禁用（v2.0 §15 沿袭）
```

## 3. 理论声明（定稿口径）

- 命题 A：SPS 输出**精确服从 b_S**（固定核 + 同对象接受/残差时；证明见 v2.0 §4.1，
  对象替换为 b_S）。
- 命题 B：`|log(b_S/π)| ≤ 2ηc` 全词表逐点成立；配 §2.4 保守记账 ⇒
  轨迹权重 ∈ e^{±B_∞} 严格成立。
- 命题 C：仅在五条件（q≡π / 记账=实际行为 / 整轨无裁剪 IS / baseline+scale
  LOO / 单快照单步）下期望梯度 = ∇J。实际实现（per-token clip 等）的偏差为
  **一阶量 O(ρH·tanh(δ_max/2))**（NF03 更正，「二阶」声明撤回），随预算线性收缩。
- 命题 D：单点二元例成立（0.219 / 86.2% / δ=1.48），不外推 episode。
- 引理 E：Cov 判据成立，本版不在线估计（留白 ②）。
