## 二、问题① 判定:不是"训不进去",是"慢速内化 + 结果的阈值放大"

**先纠正读数口径**(与 CD-006 的最终更正一致):val 就是 bare policy 的裸读数,
0.73%→13.14% 是 18×、p<1e-7 的显著提升,"没训进 bare"不成立。用户观察的
"训练 score 涨而 bare 不动"部分来自读数结构:训练 score 是两臂混合,前中期涨幅主要由
steered 贡献。

**但用户关切的实质——教师增益转化率低、gap 不收敛——成立,根因三层**:

1. **教师给的是"换序"不是新知识,且正在被内化**。拒绝位上教师换上的 token 在 π 自身
   分布中 rank 中位=1(CD-006 A5,本次复核一致);Δlogπ 中位从 1.00(s25–34)缩到
   **0.25**(s47–51),final=π-top1 占比 24%→34%,全轨迹 D_mean 与拒绝密度均降过半。
   三个独立读数与 val 上行自洽:**分布层面的知识转移确实在发生**,教师-学生分歧
   已缩小一半以上。演化结构是课程式的:低分歧位先被解决(退出拒绝集),幸存拒绝位
   的 D 先升后降。

2. **gap 拉大是阈值效应,不是分布不收敛的证据**。Δlogπ=0.25 意味着在残余分叉点,
   π 给"对的 token"的概率已达自己首选的 78%——恰在"接近但未翻越"的区间。胜负是
   argmax/采样的阈值函数:分布差一点点 → 每个分叉五五开 → 多分叉联合成功率差很多。
   教师恰好在这些点补最后一脚,且 π 执行力越强,同样的纠偏兑现的成功越多(δ 的
   杠杆随能力放大)。**δ gap 度量的是"教师杠杆的当前值",不是"未转移的存量";
   分布持续收敛下,gap 的收敛预期是相变式(翻越 argmax 后塌缩),不是线性**。

3. **慢是真的慢,三重打折是效率低的真实原因**(承认并细化 CD-006 机理一):
   教师改写仅占 token 的 0.75–4%(密度还在降,这本身是收敛的表现)× 改写位
   W=π/b 中位 0.42–0.65(IS 校正的数学必然:教师偏离越远压得越狠)× 轨迹 reward
   经 seq-mean-token-mean 均摊(96%+ 梯度花在 π 已会的 token 上)。同预算对照:
   SFT 245 条轨迹 0%→47.4%,s3 用 50 步(≈6400 条 rollout)到 13.14%。
   作为"SFT 替代通道"当前效率约差一个量级;作为"无 SFT 数据时的从零自举通道"
   它是唯一已被证明能点火的(纯 GRPO 从 0.73% 的组内全败信号大概率点不着,
   本 run 的第一批正样本几乎全部由 steered 臂制造)。

**v3.1 预注册触发条件复核**:"val 落后 won_bare_rate"——s50 已 13.14% vs 14.8%,
基本追平,**不再成立**;"δ 持续大且 val 平"——val 在涨,**不成立**。
λ± 块级校正按预注册判据当前不触发,列为观察项(触发判据改为:val 两个点不涨
且 Δlogπ 停止缩小)。

## 三、问题② 判定:主模式侵蚀→弥散化,教师非元凶;死锁与长上下文是两级放大器

**四条排除/证实**:

1. **教师(采样端)排除**:bare 臂零教师接触,长度与 steered 逐步同步膨胀
   (s51:6620 vs 6407)。膨胀只能经参数更新传导。与 OPD 时代"教师覆写压力
   (ungrounded 份额)"的病根**不同**——表象同(thinking 膨胀),病因不同。
2. **"终止 token 被压"证伪(修正 CD-006 假设二的字面版本)**:im_end 在轮末的
   概率 s51 仍为 0.9999945(仅从 0.99999988 微降);轮末倒数 2–8 位 im_end
   **从不**进 π top-16。终止是块状结构的确定性收尾(`</reasoning>→<action>→im_end`
   连锁),不存在被压低的"逐位终止竞争"。轮变长不是终止被推迟,是 **reasoning
   内容本身变长**。
3. **"轮内复读"排除**:5-gram 轮内重复率中位恒 0。变长的是**新内容**(更多枚举、
   自我论证),配合轮长直方图从锐峰(66%≤50 tok)变为摊平+右尾(23% 在 300–500),
   与熵回升(0.097→0.24)同向——**这是生成分布弥散化的形态,不是切换到某个
   长模式**。
4. **机理定形(主因)**:混合组 GRPO 下 steered 越赢、LOO 基线越高,失败 bare
   轨迹的负 advantage 单调加深(A_bare −0.004→−0.121,失败轨迹 −0.219;CD-006
   A6,方法复核无误)。失败轨迹占 bare 臂 85%+,`seq-mean-token-mean` 把负梯度
   均摊到其全部 token——**被反复压低的是 π 在失败上下文里的主模式(短促确定的
   reasoning 短语、死锁短句)。压掉主模式而失败任务上无正样本提供替代模式,
   概率质量只能流向长尾 → 分布弥散 → 每轮更长、熵回升;更长的失败轨迹继续
   全 token 挨压,正反馈成环**。时间锚一致:A_bare 深负化、熵触底回升、
   长度起飞都在 s34–35,正是 steered 甩开 bare(gap +6→+22)的起点。

**两级放大器**:

- **死锁吸子**:`look`/非法动作 → "Nothing happens." → 上下文不变 → 逐字重复,
  `max_env_steps=30` 下失败轨迹免费打转,死锁贡献失败轨迹 60–70% token。
  死锁轮长与正常轮长全程同步 ⇒ 它把"每轮膨胀"按重复次数放大(轨迹级 4–5×),
  本身不是膨胀的起因(第一波死锁率升至 73% 时总长反而在降)。
  另一发现:**自条件化教师对死锁失明**——死锁上下文里 p_T(=π+doc)同样预测重复,
  D→0、拒绝位后期集中到轨迹前 16%,教师在死锁区无异议可提;steered 死锁率低于
  bare(0.38 vs 0.58)靠的是前段纠偏少入死锁,不是后段破锁。
- **长上下文条件化**:轮长随轮号递增(样例 70→758→533×20),后段生成条件在
  越来越长的失败上下文上,弥散进一步加剧。

**s2 反例佐证**:同机制(B=400/有门/SFT 起点,GT doc)的 A800 s2 臂全程无膨胀
(step70 val 93%,平均响应 503 tok)。s2 高胜率 ⇒ 失败轨迹是少数 ⇒ 负梯度不主导。
s3 的 raw 起点决定它长期滞留低胜率区间,负梯度主导是**结构性**的。

**运行风险时间表(非"并行的效率问题"可安置)**:单轨迹 max 已 27,676 =
预算 84%,respLen 近 8 步 +330/step。一旦大面积撞 32768:截断按现约定判输
(撞墙行负 advantage),且截断会把能力上升伪装成下跌([[truncation-masks-capability]])
——膨胀从效率问题升级为读数污染与假崩塌。**必须在撞墙前处置,窗口约 15–20 步**。

## 四、机制改进方案(按对症与代价排序;均需用户裁定,本分支不擅动)

### P1(建议立即,双双对症问题②,兼利问题①)

1. **口径 B:两臂分组 GRPO**(v3.1 设计留白,advantage 分组 key 一处改动)。
   拆除"steered 越赢 → bare 全轨迹挨压越重"的结构:bare 全败组退化为零梯度
   (不再弥散化压制),bare 有赢组内部对比、正 advantage 反而更大(baseline 是
   bare 均值而非混合均值)——**既砍问题②的主因,又加强 bare 自己成功的强化**
   (利问题①)。丢失的只是"同任务教师能成/你不能"的对比负信号——本诊断证明
   该信号作用在错误对象上(压的是全轨迹而非分叉)。代价:组 8 条,LOO 方差升
   (历史 n=8 run 均可跑)。进 objective_fingerprint。
2. **无进展截断(no-progress cut)**:连续 K 轮 (thought, action) 逐字相同 ⇒
   终止 episode,结局照旧判输、reward 不动。与既有 `MAX_CONSECUTIVE_FORMAT_FAILURES=3`
   同格(协议层信号,零任务语义);K=3 起步。效果:失败轨迹 token 5–6k → ~1.5k,
   拆除死锁放大器、解除 ctx 撞墙风险、rollout 墙钟大降。属采样协议(episode caps
   先例,不进指纹),但影响轨迹分布,按纪律先经裁定。

### P2(观察触发,预注册好判据再动)

3. **λ± 块级校正 / 拒绝位 W floor**:预注册触发判据改为"连续两个 val 点不涨
   且 Δlogπ(M3)停止缩小"。当前两条旧判据均已不满足,不动。
4. **退火(断奶)调度**:Δlogπ 已入 0.25 区间,若 val 继续上行,可在 gap 首次
   收缩后启动 steered_fraction 或 η 退火,逼 policy 翻越 argmax;过早断奶有回退
   风险,二阶段再议。
5. **w_beh_mode=off 消融臂**:量化"IS 校正花了多少学习速率"(问题①三重打折的
   第二重是否值得付),论文消融价值高,等卡。

### 监控增量(不改机制,建议 CD-006 采纳)

- M3 三曲线进日常监控:拒绝位 Δlogπ 中位 / final=π-top1 率 / 拒绝密度
  (`s3_deep.py` 可直接复用);它们是"最后一公里"的进度条,比 δ gap 可解释。
- respLen max 距 32768 的余量单列告警(<10% 即红)。
