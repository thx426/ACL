# PGS 预算均衡化设计(裁定版:解锁曲线族 pacing)

CD-010,2026-08-05。触发:s1 首查实测干预位置坍缩。用户裁定链:
① 同意 pacing 思路方向,并提出**衰减解锁**变体(轮次递减,预算重心前移);
② **通用性红线**:机制只用任务无关信号,凭 ALFWorld 先验设计的组件
(失败触发 bonus、重复率触发等)一律不进机制;③ B_∞ 20→400(v4 探索档,
"作用到多轮长轨迹要显著提升");④ B 自适应与训练期衰减调度记账后议(§3)。

## 0. 设计原则(用户裁定,机制级红线)

机制可依赖的信号仅限三类,保证跨 benchmark 通用:
1. **时间/结构**:turn 进度、环境硬配置(`max_assistant_turns` 等 horizon 上限);
2. **机制内生量**:D、ℓ̃、预算余额、门率;
3. **两个分布本身**:π 与 p_T。

任务语义信号(动作失败文本、重复率、子目标完成等)不进机制——不同任务
情况不同,不能凭当前 benchmark 的先验认识设计。

## 1. 问题(s1 step 1–17 实测,2176 轨迹;审计脚本见 §6)

- 1158 次拒绝重采 98.7% 落在 turn 0,位置中位=轨迹**前 0.4%**(P99 仅 6%);
  换 token 仅 ~0.56 次/轨迹。机制退化为"只修饰第一段 reasoning 开头"。
- 因果链:预算**贪心顺序花费** × 头部 D 厚尾 ⇒ 8 次额度在前 ~100 token 花光
  ⇒ 其后整轨迹 bypass(candidates≈20/轨迹=截断窗口)。
- 结构约束:token 流式生成 ⇒ 只能在线分配(全轨迹 verify 后挑最大 D 不可行:
  100× 教师成本 + 破坏 speculative 恒等);Σδ≤B_∞ 不可破(W_beh IS 界的根据)。

## 2. 方案:解锁曲线族(token-bucket pacing)

**turn t 开始时的累计解锁额度**:

    unlocked(t) = U0 + (B_∞ − U0) · φ(t / T_max),   φ(x) = 1 − (1−x)^p

可花额度 available(t) = unlocked(t) − spent。开门位置若 available < δ 则
bypass(计 `n_budget_blocked`,与总额耗尽区分)。

- **p = 1**:匀速解锁(直线);
- **p = 2**:解锁速率随轮次线性衰减(用户提议的"均匀衰减"档,**默认**)——
  预算重心前移(早期 credit 大、规划期文档相关性高)但全程非零、尾部兜底;
- 现状(无 pacing)= 阶跃在 t=0(实测坍缩),p→∞ 的极限;
- **U0**(默认 5.0 = 2×δ_full):头部初始拨付,保任务理解期纠错(s1 实测
  头部改写含真纠错:drawer→soap、find→put);
- **T_max = `episode.max_assistant_turns`**(环境硬配置,零先验——不预测
  轨迹长度;任何有限 horizon 的 agentic 任务都有此配置,通用);
- **token-bucket 攒额**:剖面只定供给上限,实际消费由 D 门定;异议少的时段
  额度自动流转到后段异议处——机制内生的自适应,不依赖任务信号。

**自动获得的性质(事后效应,非决策依据)**:短轨迹提前结束 ⇒ 后段解锁未
发生 ⇒ 自动少花;长(经验上=困难)轨迹覆盖到尾。全程仅用已实现历史,因果
性无破绽。

**参考账**(B=400、δ=2.5、U0=5——用户裁定 v4 探索档;共 160 次整额,单位=次):

| turn 段 | p=2(默认) | p=1(匀速) |
|---|---|---|
| 0(U0) | 2.0 | 2.0 |
| 1–10 | 69.1 | 39.5 |
| 11–20 | 49.4 | 39.5 |
| 21–30 | 29.6 | 39.5 |
| 31–40 | 9.9 | 39.5 |

B=400 下 160 次整额 ≈ 全轨迹候选(标定口径 ~2160/轨迹)的 7.4%,与 q=10%
门率(≈216 次开门)接近匹配——预算从硬瓶颈转为轻约束,"过门即大概率可花";
pacing 剖面决定各段配额上限。预期换 token ≈ 160×(7–10%) ≈ **11–16 次/轨迹**。

**⚠ 墙钟预警(B=400 的内生代价)**:s1 的 verify 只发生在头部 ~150 token
(便宜);B=400+pacing 下 steerable 时段≈全轨迹 ⇒ verify 覆盖 ~全部响应
token。vLLM 对 prompt_logprobs 请求禁 prefix-cache 读 ⇒ 每 turn 的 verify
都全前缀重算,成本 Σ_t(prefix_t) 呈平方型:中位轨迹(~8k token)估
~24 万 prefill token/轨迹,**预计墙钟 2–4× base**(长轨迹 step 更差)。
s2 首 step 实测定夺;若不可接受,缓解排序:① verify 段长上限(牺牲部分
覆盖);② 教师侧有状态 KV(中期工程);③ B 回摆。

**与率控的耦合红利**:pacing 使 verify 窗口散布全轨迹 ⇒ tracker 观测口径
≈ 全轨迹分布 ⇒ 标定初值 θ=0.0338 即近均衡(s1 的"头部窗口口径断裂"不修而愈)。

## 3. 排除项与二版留白

- **失败/重复等任务语义触发**:用户裁定排除(通用性红线,§0)。
- **θ–预算联动**(门槛随剩余预算/剩余时间调整,receding-horizon 轻量形态):
  任务无关、原理成立,但为保首轮观测清晰(EMA 刚修复)**推迟二版**;
  spec §5 已挂账。
- **预算匹配率控**(θ 逼到 top-B 选位):依赖"极端 D 不堆头部"假设,现无
  数据可验;二版消融。B=400 后预算-门率已接近匹配,该方案的动机部分被吸收。
- **记账口径改实际消耗**(δ=2ηc 保守 ~15×):动 spec 冻结定义,挂账待裁定。
- **B_∞ 自适应**(用户 2026-08-05 记账,暂不实施):跨 benchmark 时一次
  先验标定不适用,B 应可自适应(如按候选量/门率在线定标)。
- **B_∞ 训练期衰减调度**(用户 2026-08-05 记账,暂不实施):类 lr cosine——
  训练早期学生弱、教师多干预,随任务成功率提升 B 退火 → 渐趋纯 on-policy。
  与 OPD 文献的 teacher annealing 同构,论文叙事友好。
